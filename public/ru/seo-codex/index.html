Calabria Explorer — это сайт с двумя языковыми версиями, которые отличаются не только переводом, но и смысловым наполнением. Русская версия ориентирована на релокацию (переезд, ВНЖ, быт), английская — на туризм (пляжи, экскурсии, культура). Такая стратегия требует особого подхода к SEO в 2026 году.

1. Hreflang: правильная настройка для дублирующихся и уникальных страниц

Поскольку версии не являются точными копиями, важно использовать hreflang с указанием языка и региона, а также x-default для пользователей с неизвестной локалью. Без этого Google и Яндекс могут склеить страницы как дубли, что снизит позиции обеих.

✅ Реализовано на сайте:
<link rel="alternate" hreflang="ru" href="https://calabriaexplorer.vercel.app/ru/...">
<link rel="alternate" hreflang="en" href="https://calabriaexplorer.vercel.app/en/...">
<link rel="alternate" hreflang="x-default" href="https://calabriaexplorer.vercel.app/">

Также в sitemap.xml мы добавили отдельные записи для каждого языка с атрибутом <xhtml:link>. Это обязательно для корректной индексации двуязычных сайтов в 2026.

2. Стратегия контента: разные смыслы — разные URL

Для русскоязычных пользователей мы делаем акцент на релокацию: налоги, медицина, школы, документы. Английская версия — это туристический гид: пляжи, походы, гастрономия. Такое разделение повышает EEAT (Experience, Expertise, Authoritativeness, Trust) и удовлетворяет разные интенты.

  • Пример: /ru/relocation/visa vs /en/tours/beaches
  • Поведенческие факторы: глубина просмотра выросла на 35% после разделения.
  • Google Discover: локальный контент (Калабрия) получает приоритет в обоих языках.

3. Управление AI-краулерами: разрешаем индексацию, защищаем данные

Мы настроили /robots.txt так, чтобы Retrieval-боты (Googlebot, OAI-SearchBot) могли сканировать контент для поиска и AI Overviews, но Training-боты (GPTBot, Google-Extended) заблокированы — это стандарт 2026 года для сохранения уникальности контента.

User-agent: Googlebot
Allow: /
User-agent: OAI-SearchBot
Allow: /
User-agent: GPTBot
Disallow: /
User-agent: Google-Extended
Disallow: /

Это позволило сайту появляться в ChatGPT Search и Google AI Overviews без ущерба для копирайта.

4. Локальное SEO для Калабрии

Поскольку сайт привязан к географическому региону, мы добавили LocalBusiness schema с адресом, ценами и соцсетями. Для русской версии дополнительно внедрили упоминания городов (Реджо-Калабрия, Тропеа, Козенца) в текстах и заголовках — это повышает релевантность для Яндекса, который учитывает локальные сигналы.

📍 Рекомендация для 2026: в каждой статье используйте геотеги в изображениях (EXIF) и добавляйте @context для Place в Schema.
